Project concept

Overview

ARTHAŚĀSTRA is an educational secure-dispatch simulation. It brings together classical ciphers, message authentication, receiver clearance, and basic cryptanalysis in one interactive interface.

Security boundaries

Read before demo
Not production cryptography. Caesar and Vigenère ciphers are weak and easily broken. HMAC authenticates data but does not encrypt it.
  • Do not use real credentials or confidential messages.
  • The demo secret key is held only in the current browser page.
  • HMAC detects edits to the signed fields when the key remains secret.
  • Clearance is a local simulation, not an identity or authorization service.
  • For real systems, use vetted authenticated encryption such as AES-GCM or a modern secure protocol, with proper key management.
